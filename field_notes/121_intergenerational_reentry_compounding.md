Status: Prior adopted / verification pending

## Core Claim

Ordinary model comparison treats model capability as a difference in the quality of one answer. In long-horizon human-AI work, a preserved artifact can also change the starting point of later loops and the branch set later models can reach.

> Model capability determines reachable distance. Re-entry-ready structure determines the starting point.

> Compounding does not only improve the quality of the next artifact. Once a preserved structure exceeds a sufficient threshold, it can make previously unreachable questions, structures, and branches accessible.

## Primary Observation: V5 -> V8 -> V9

The V5 -> V8 -> V9 lineage is the primary observation.

V5 did not merely make V8 slightly better. Its confirmation, revocation, safety, and responsibility structure may have made V8's abstraction into trajectory, reversibility, and Seat possible.

V5-V8 then remained as externalized artifacts when the model environment changed. Conflict with later hindsight-oriented behavior could therefore be interpreted structurally and converted into V9's As-of Fixation, Playback-only, Forward-only Update, and Seat fixation.

Without accumulated structure, the same event may have remained only a complaint that the model changed.

## Intergenerational Mechanism

A later model can reuse prior-generation work without rediscovering it only when the structure is externalized into artifacts such as definitions, boundaries, counterexamples, evidence, papers, README or Field Notes, operational rules, and completion or re-entry conditions.

```text
Intergenerational re-entry
= structural strength
× re-entry maturity
× receiving-model interpretation and extension capacity
```

If any component is weak:

- weak structure: rediscovery begins again;
- weak re-entry maturity: the receiving model fills gaps with plausible narrative;
- insufficient model capacity: the structure may be read but not correctly extended.

## Required Re-entry Conditions

Where relevant, a reusable artifact should preserve:

- As-of state;
- fixed boundaries;
- evidence or provenance;
- what is complete;
- what remains `HOLD` or unresolved;
- what must not be changed;
- re-entry trigger or next action;
- current ownership;
- receiving-side acceptance.

An artifact's existence alone is not a completed handoff.

## Boundary and Non-Claims

Do not claim that:

- better models automatically create better long-term trajectories;
- stored artifacts are automatically reusable;
- model capability no longer matters;
- accumulation always expands branching;
- this is already an independent universal theory.

Poor structures can create lock-in, debt, or narrower future branches. The conditional claim is that strong, reusable, re-entry-ready structure can raise the next model's starting point and may activate branches that otherwise would not exist.
