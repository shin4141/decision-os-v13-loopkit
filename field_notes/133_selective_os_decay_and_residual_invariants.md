## 1. Why this note exists

A sequence of controlled experiments asked whether explicit Decision-OS scaffolds still add marginal value when used with a stronger current model.

The emerging result is not that Decision-OS was simply wrong.

A better interpretation is selective decay:

> Some explicit reasoning scaffolds lose marginal value as model intelligence improves, while state, authority, admission, and ownership invariants can remain structurally necessary.

The As-of distinction matters. A control that was useful at an earlier capability level can later become partially native without retroactively invalidating the original failure boundary.

## 2. Intelligence-Substitutable Components

### V12 Completion Integrity test

A fixed V12 Completion Contract was tested against the strongest native model baseline.

Observed disposition:

```text
HOLD — CONTROL FLOOR EFFECT / NO INCREMENTAL PRODUCT VALUE ESTABLISHED
```

The native control already handled the tested completion/restartability problems well enough that the treatment did not establish added value and missed some closure elements.

Interpretation:

- false-completion detection can become partially native;
- restartability reasoning can become partially native;
- this does not eliminate the value of actual completion records, evidence, or handoff state.

### V13 Pre-Loop Gate test

A fixed pre-loop Gate was tested for branch-changing, propagating, cheaply resolvable unknowns.

Observed disposition:

```text
HOLD — CONTROL FLOOR EFFECT
```

The native control produced zero downstream contamination and zero regeneration in the frozen cases. The treatment prevented no additional events and introduced one false stop.

Interpretation:

- premise checking and AI-side pre-resolution can become partially native;
- the added contract can become friction once the baseline already reaches the behavioral floor.

### V11 Rare-Path Erasure test

A test asked whether outcome-only memory caused a strong model to reconstruct a likely but unsupported causal path.

Observed disposition:

```text
HOLD — WEAK / NO RARE-PATH ERASURE EFFECT
```

The model preserved uncertainty and did not invent unsupported causes.

Interpretation:

> State is not always required for safe continuation.

Strong intelligence can sometimes compensate for missing causal-path detail by preserving uncertainty.

## 3. Residual State Invariant: Admission / Regime Membership

A second V11 experiment changed the question.

Instead of asking whether the model invents a missing cause, it asked what happens when an anomalous or regime-breaking observation has already been admitted into the ordinary data pool.

Observed O-13 disposition:

```text
GO — QUARANTINE MARKER SUPPORTED
```

Frozen result summary:

- `UNMARKED_POOL` admission errors: 2
- `FULL_REGIME` admission errors: 0
- `UNMARKED_POOL` future-policy distortions: 2
- `FULL_REGIME` future-policy distortions: 0
- `QUARANTINE_MARKER` prevented distortions in episodes 01 and 04
- `QUARANTINE_MARKER` matched `FULL_REGIME` decision quality 4/4

This supports a narrower State residue:

> The important missing state may not be the full causal story. It may be the admission status that determines what distribution or regime an observation is allowed to enter.

### Regime Contamination

Definition:

> Regime Contamination occurs when a real observation whose generating regime is anomalous or unresolved is admitted into an ordinary pool before its regime membership is resolved.

This is not equivalent to an ordinary outlier.

```text
Outlier != Regime Violation
```

An outlier may still belong to the ordinary generating process. A regime violation may come from a materially different generating process.

### Quarantine Admission

Minimal rule:

> Preserve the outcome. Quarantine its meaning until regime membership is resolved.

Minimal fields:

```text
outcome
regime_status = normal / anomalous / unresolved
admission_status = ordinary_pool / quarantine
evidence_or_reentry_anchor
```

Quarantine is not deletion. The observation remains preserved and reconnectable while its ordinary-pool meaning remains uncommitted.

### Contamination Debt

Definition:

> Contamination Debt is the future clean-sample, re-analysis, threshold-repair, rollback, and audit cost created by admitting a regime-breaking observation into the wrong ordinary pool.

This is close to mislearning: the value itself can be real while its distribution membership is wrong.

When the true edge is small and the contaminating observation is large, one wrong admission can require many later clean observations merely to dilute a sample that should never have been pooled.

## 4. Residual Authority Invariant

A local no-cost reachability harness tested four frozen scenarios:

1. cost cap;
2. iteration cap;
3. publication boundary;
4. destructive-scope boundary.

Across all four:

```text
DECLARED_ONLY
  -> prohibited state reachable

ENFORCED_BOUNDARY
  -> prohibited state unreachable

CONTEXT_LOSS_WITH_ENFORCEMENT
  -> prohibited state still unreachable
```

Legitimate goal states remained reachable under enforcement.

This strengthens the existing Model-Independent Gate Enforcement direction in Field Note 123.

Field Note 123 already records:

> A recorded rule is not an enforced rule.

The new reachability result sharpens the distinction:

> Intelligence governs choice. Authority governs reachability.

A strong model can choose not to cross a boundary. That is behavioral compliance.

Authority changes whether the prohibited transition exists in the executable action graph.

A paid model stress test was not run because attempt frequency would add little evidence to the structural reachability distinction.

## 5. Seat: Structural Invariant, Behavioral Floor

A local Seat state-transition harness distinguished:

```text
UNSET
INFERRED_PREFERENCE
OWNER_SELECTED
DELEGATED
AI_SELECTED_UNDER_DELEGATION
```

The prohibited semantic transition is:

```text
INFERRED_PREFERENCE -> OWNER_SELECTED
```

without a new owner-selection event.

Correct prediction changes epistemic confidence. It does not create a historical ownership event.

A paid O-14 model test then asked whether the native model already preserves this distinction without an explicit Seat contract across durable record creation and fresh future-agent reuse.

Observed disposition:

```text
HOLD — NATIVE SEAT PROVENANCE FLOOR
```

Frozen result summary:

- 25/25 calls completed;
- technical retries: 0;
- all four `INFERRED_ONLY` cases preserved provenance across both stages;
- reversible preparation remained available 4/4;
- Stage-2 isolation passed;
- no added Seat contract was required to achieve the tested provenance behavior.

Interpretation:

The structural Seat distinction remains real:

> Intelligence can predict a choice. Seat records who actually made it.

But the tested strong native model already preserved that distinction behaviorally in the frozen cases.

Therefore Seat has two separable aspects:

1. **Seat reasoning / provenance handling** can reach a native behavioral floor.
2. **The ownership event itself** remains an external historical fact. Correct inference cannot manufacture that event.

## 6. Revised Decay Map

The experiments suggest four classes:

```text
I = Intelligence-substitutable
S = State-required
A = Authority-required
H = Human / Seat-required
```

The important update is that whole Decision-OS versions do not simply decay at once.

Decay is selective by function.

### I — likely to lose marginal scaffold value

Examples observed in the frozen tests:

- generic completion/restartability reasoning;
- ordinary pre-loop premise checking;
- uncertainty preservation under missing causal path;
- Seat provenance handling in the tested context.

### S — residual candidate

Most resistant when State controls:

- exact provenance;
- evidence identity;
- admission status;
- regime membership;
- re-entry anchors;
- commitment boundaries.

### A — structural residual

Authority remains distinct when it changes prohibited-action reachability rather than merely telling a model what not to do.

### H — mixed residual

A strong model may infer and preserve likely owner preference correctly.

But the fact that the owner actually selected, delegated, or accepted a tradeoff remains a historical event rather than a model inference.

## 7. Current Working Hypothesis

The strongest current form is:

> Intelligence can substitute for some missing reasoning and some missing state interpretation. It cannot always substitute for a wrong admission, an executable authority boundary, or the historical fact of who made a decision.

This gives a more precise reading of Decision-OS aging:

```text
Scaffold may decay.
Invariant may remain.
```

The important research question is therefore no longer:

> Does Decision-OS still work?

It is:

> Which Decision-OS functions are still marginally useful at the current intelligence level, and which are already native while their underlying invariant remains real?

## 8. Non-Claims

Do not claim from these experiments that:

- OpenAI or any model developer adopted Decision-OS;
- Decision-OS caused current model behavior;
- all V12, V13, or Seat controls are obsolete;
- State is generally unnecessary;
- every anomalous sample should be quarantined;
- the O-13 synthetic result proves broad real-world generalization;
- a strong model can create owner authorization by correctly predicting it;
- behavioral compliance is equivalent to runtime enforcement.

The observed pattern is compatible with independent convergence or native capability improvement.
